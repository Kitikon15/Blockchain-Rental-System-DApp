# 📦 Blockchain-Based Rental System (BlockRental)
> **ระบบจัดการการเช่าแบบกระจายศูนย์บนบล็อกเชน (Decentralized Web3 Rental Platform)**  
> พัฒนาด้วย Next.js 14, JavaScript (ES6+), ethers.js v6, Bootstrap 5.3, MetaMask และ Ethereum Sepolia Testnet

---

## ⚡ เริ่มต้นใช้งานด่วน (Quick Start)

```bash
# 1. เข้าสู่โฟลเดอร์แอปพลิเคชัน
cd digital-rental

# 2. ติดตั้ง Dependencies
npm install

# 3. รัน Development Server
npm run dev

# 4. เปิดดูผ่านเบราว์เซอร์
# เข้าไปที่ http://localhost:3000
```
